### 🏆 Projetos em Destaque

**1. Monitoramento Avançado de Redes: Grafana + API PRTG (Destaque)**
* **Descrição:** Construção de dashboards dinâmicos no Grafana consumindo a API nativa do PRTG Network Monitor, eliminando a necessidade de bancos de dados intermediários. O projeto monitora tráfego e saúde de equipamentos de ponta, incluindo FortiGate (VLANs, VPNs), F5 Networks (WAF), Switches Cisco e Servidores Windows (WSUS/Qlik Sense In-Memory). O projeto conta com uma V1 (desenvolvida em Python com SQLite) e a arquitetura V2 atual em tempo real.
* **Tecnologias:** Grafana, PRTG, Python, APIs REST, JSON/CSV.

**2. Otimizador de Windows (Batch Script)**
* **Descrição:** Script Batch de manutenção do Windows: verifica privilégios de administrador, executa SFC e DISM, limpa o cache DNS e arquivos temporários, agenda o CHKDSK e registra tudo em log.
* **Tecnologias:** Shell/Batch, Windows OS.

**3. Website Pessoal (Versão 1.0)**
* **Descrição:** Landing page criada para estruturação de portfólio, servindo como base para a hospedagem estática via GitHub Pages.
* **Tecnologias:** HTML5, JavaScript, CSS3.

**4. Calculadora Gráfica - MARIE Assembly**
* **Descrição:** Projeto de arquitetura de computadores que implementa um motor de renderização gráfica nativo. Desenvolvida inteiramente em Assembly (sem instruções complexas nativas), a calculadora constrói a própria ALU para as 4 operações básicas e desenha os caracteres (números e avisos de erro) diretamente no display do simulador manipulando ponteiros de memória de vídeo.
* **Tecnologias:** Assembly (MARIE), Arquitetura de Hardware, Lógica de Baixo Nível.
